# DexBinder v0.9.4b — Achievement Colours + Add Cards

Two UX refinements:

1. Achievement Cabinet reached tiers now colour the full category card. Bronze,
Silver, Gold and Diamond use distinct restrained backgrounds. Inside category
details, every milestone already reached also receives its tier colour while
future milestones remain neutral.

2. Fast Add and Scan are consolidated into one dashboard action: Add Cards.
The launcher offers Search & Add (existing Fast Add) and Scan Card (existing
Scan Assist). The underlying workflows and collection data remain unchanged.

Collection thresholds remain 1,000 / 5,000 / 10,000 / 15,000.
No schema migration is required. Cloud Sync remains unchanged.
