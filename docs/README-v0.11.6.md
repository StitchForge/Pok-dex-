# DexBinder v0.11.6 — Hero & Umbreon contrast polish

Changes:
- Hero characters reduced in size so they frame the scene instead of dominating it.
- Removed the lower cross-hatched / fence-like tree-line layer.
- Replaced lower scenery with softer mountain silhouettes.
- Theme orb is solid gold in Espeon, blended only in System, and solid silver in Umbreon.
- Umbreon modal Close buttons now always use light text on a dark button.
- Light/cream cards inside Umbreon modal sheets now explicitly use dark navy headings/text and charcoal secondary text.
- Dynamic light-surface contrast fallback is retained.
- Existing Watchtower Chase Picks, grouped sets, set logos, achievements, Trade & Hunt, Acquisition History, backup/restore and cloud foundation are retained.
