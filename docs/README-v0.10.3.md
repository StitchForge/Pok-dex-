# DexBinder v0.10.3 — Watchtower Chase Picks + Visual Consistency

## Automatic Chase Picks
Priority is now:
1. Your custom Chase Pick
2. Curated TCG Watchtower top-market chase for the set
3. Existing DexBinder fallback logic

The visible label remains simply “Chase Pick”.
Reset to automatic returns to the Watchtower card where mapped.

## Dashboard banners
When a set logo is available, the repeated series and set name underneath it are removed.
If the logo is unavailable, text remains as the fallback identity.

## Add Cards
The primary Add Cards button now changes with Espeon / Umbreon / System instead of remaining one fixed saturated blue.

## Secondary page heroes
Set pages, Global Hunt, Set Library, and Trade destination screens now use the same theme-aware hero family as the homepage for stronger contrast and visual consistency.

No collector schema or cloud payload migration is required.
