# DexBinder v0.7.1 — Trade List + Trade Basket

New:
- Dedicated Trade List for cards marked "Available to trade"
- TCGplayer reference value per trade line
- Quantity-aware total trade value
- Trade Basket for quick on-the-fly totals
- Sorting:
  - Recently added
  - Highest value
  - Lowest value
  - Set
  - Card number
  - Condition
  - Quantity
  - Duplicates first
- Filters:
  - All trades
  - Duplicates only
  - Priced only
  - Per-set filter
- Remove a card from trade directly from the Trade List
- Trade list summaries for unique lines, total copies, and total reference value

Notes:
- Trade values are reference values only.
- They currently use DexBinder's existing TCGplayer variant pricing and do not apply condition/language adjustments yet.
- Trade Basket is intentionally temporary and is not included in Backup/Restore.
