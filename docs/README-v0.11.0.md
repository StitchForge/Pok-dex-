# DexBinder v0.11.0 — Interactive Sky Hero

The homepage greeting hero is now the theme control.

- Continuous day → twilight → night landscape
- Sun/moon orb follows the finger 1:1 while dragging
- Release snaps to Umbreon night, System twilight, or Espeon day
- Stars twinkle and meteors animate at night
- Clouds and birds move during the day
- App theme updates to match the snapped state
- Keyboard-accessible slider
- Reduced-motion support
- Collector Tools remains available through a dedicated hero button
- Old header theme switch removed
- Existing Watchtower Chase Picks, set grouping, achievements, trade, acquisition, backups and cloud foundation retained
