# DexBinder v0.11.2 — Interactive Sky refinement

This build fixes the remaining v0.11 theme issues:

- Espeon/day remains on the LEFT and now correctly displays a SUN.
- Umbreon/night remains on the RIGHT and now correctly displays a MOON.
- The day/night interpolation variables were corrected so the draggable orb changes icon in the correct direction.
- Espeon and Umbreon are now bundled as transparent character layers rather than rectangular scene crops.
- Full-page environments are animated:
  - Espeon: moving gradient light, drifting clouds and distant birds
  - Umbreon: ambient glows, twinkling stars and occasional shooting stars
  - System: gently animated twilight
- The page body is transparent so those atmospheric layers remain visible behind the interface.
- Reduced-motion support is retained.
- Existing Watchtower Chase Picks, set grouping, achievement, trade, acquisition and backup functionality remain intact.
