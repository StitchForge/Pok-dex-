# DexBinder v0.9.0 — Wishlist & Collection Goals

First release of v0.9 Collection Intelligence.

New:
- Wishlist quick action
- Wanted state per exact card variant
- High / Medium / Low priority
- Optional target price
- Wishlist notes
- Wishlist search and priority filtering
- Custom completion target per active set
- Goal progress and nearest-goal summary
- Wishlist + goals included in Backup / Restore

New storage keys:
- dexbinder_v09_wishlist
- dexbinder_v09_set_goals

Existing ownership, collector metadata, trade history and cloud schemas are unchanged.
Cloud Sync is deliberately not expanded yet.

v0.8.8 Scan Assist and all previous collection/catalogue/trade features are retained.
