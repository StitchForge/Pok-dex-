# DexBinder v0.10.0 — Mobile Redesign

Presentation-layer redesign inspired by the new DexBinder dashboard direction.

Highlights:
- Espeon light theme
- Umbreon dark theme
- System theme option
- saved appearance preference
- redesigned dashboard hierarchy
- artwork-rich Active Set cards
- horizontally swipeable Active Sets on mobile
- horizontally swipeable Achievement Cabinet on mobile
- Add Cards remains the primary action
- Wishlist and Trade & Hunt remain prominent
- Manage Sets / Data & Sync are secondary utilities
- existing v0.9.4c chase-art treatment retained

No collector schema or cloud payload migration is required.
