# DexBinder v0.10.5 — Day & Night Polish

Changes in this build:
- Celestial orb now follows the pointer continuously while dragging and snaps only on release.
- Day/night horizon is straight.
- Umbreon has pulsing/twinkling stars and occasional shooting stars.
- Espeon has a layered animated sky, moving glow and drifting cloud layers.
- System has a restrained animated twilight treatment.
- Reduced-motion support remains.
- Umbreon contrast now includes a runtime surface classifier: light cards inside dark sheets are detected by computed background luminance and receive dark typography.
- Temporal Forces uses the corrected user-supplied transparent logo bundled locally at assets/temporal-forces-logo.png.
- Generic set-logo fallback remains for other sets.
- Existing Chase Pick / Watchtower defaults / achievements / trade / acquisition functionality is retained.
