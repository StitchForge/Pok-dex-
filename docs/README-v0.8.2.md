# DexBinder v0.8.2 — Catalogue Navigation

## All Sets is now collector-friendly

Fast Add → All Sets now supports:

- Era / series chips
  - Scarlet & Violet
  - Sword & Shield
  - Sun & Moon
  - XY
  - Black & White
  - older eras when present in TCGdex
- Year filter
- Sort selector:
  - Newest first (default)
  - Oldest first
  - A–Z
- Era + year grouping in chronological views
- Cleaner metadata under each set name
- Existing "In My Dex" indicator retained

## Default ordering
Newest first is now the default catalogue order.

## Filtering model
Filters work together:
- search text
- era
- year
- sort mode

## Release data
DexBinder uses TCGdex release-date / series metadata when supplied.
There are defensive fallbacks for older or incomplete catalogue records.

## Existing v0.8 features retained
- Global catalogue card entry
- Fast Add
- Save & Next
- Raw / graded groups
- Collector metadata
- iPhone zoom-on-tap hardening
- Active-set auto-add when recording a card from the global catalogue

No cloud schema changes.
