# DexBinder v0.9.4 — Achievements & Milestones

Adds a dynamic achievement system calculated from existing DexBinder data.

Categories: Collection, Sets, Trades, Grading, Acquisition.

Tiered Bronze / Silver / Gold / Diamond milestones include physical-card count,
completed sets, completed trades, graded-card count, per-set completion and
era completion. Collector Tools includes Achievements, and the dashboard shows
a compact Latest milestone card.

No schema migration is required. Cloud Sync remains unchanged.
