# DexBinder v0.9.4c — Chase Artwork Dashboard

Active Collection cards now gain dimensional background artwork after their
set data is available. DexBinder dynamically selects an artwork-bearing card
from the later-numbered/special end of each loaded set and uses the real TCGdex
card image as a translucent background.

A strong readability gradient keeps set name, counts and completion progress
clear. If artwork has not loaded yet, the card gracefully keeps the standard
neutral background.

Retained from v0.9.4b:
- Add Cards launcher merging Search & Add + Scan Card
- Achievement Cabinet tier background colours
- Collection Size thresholds 1,000 / 5,000 / 10,000 / 15,000
- Trade & Hunt navigation
- Global Hunt exact-card detail
- Acquisition History
- stable data/image caches

No schema migration or cloud payload change.
