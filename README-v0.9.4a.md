# DexBinder v0.9.4a — Achievement Cabinet

Refines v0.9.4 into one visual progression card per achievement category.

Collection Size thresholds:
- Bronze: 1,000 physical cards
- Silver: 5,000
- Gold: 10,000
- Diamond: 15,000

Each category card now shows one icon, current tier, current value, a circular
progress indicator, progress toward the next tier, and a tap-through detail
view. Set and Era detail views retain granular progress without crowding the
main cabinet.

Acquisition uses a custom progression based on recorded provenance and
acquisition-type diversity.

No schema migration is required. Cloud Sync remains unchanged.
