# DexBinder v0.7.3d — Collection Banner Navigation

Changes:
- The large "Your Collection / My Dex" banner at the top of the home screen is now tappable.
- Tapping it opens Collector Tools.
- Keyboard accessibility added for Enter / Space.
- The separate "Collector Tools" button has been removed from the Active Collections controls.
- Backup, Trade and Sync remain in the action row.

No collection data, collector metadata, trade history, cloud configuration, or inventory schema changes.
